# inoSOLAR — pre-calcul materiale

Aplicație web, într-un singur fișier (`index.html`), pentru pre-calculul și raportarea materialelor la sistemele fotovoltaice de 3–30 kWp. Lucrează și fără semnal; conturile și sincronizarea trec prin Supabase.

- În pagină stă doar cheia publică a proiectului Supabase. Accesul la date îl controlează regulile din baza de date (Row Level Security).
- Conturile le creează Adminul, din aplicație. Înregistrarea liberă e oprită.
